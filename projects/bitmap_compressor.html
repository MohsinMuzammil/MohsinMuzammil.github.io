Bitmap Image Compressor

A Python image compressor that uses quadtrees and recursion to compress bitmap images with a user-controlled loss level.

March 2021 Python · Algorithms · Data Structures

Overview

This is one of my favourite projects because of its practicality. I programmed a bitmap image compressor in Python whose core ideas are recursion and trees.

The idea is to store an image as a quadtree — a tree data structure where each node has exactly four children. We begin by splitting the image into four quadrants, and each quadrant is split recursively until we reach individual pixels. Individual pixels become the leaves of the tree.

Compression with a Loss Level

To compress an image, the user provides a loss level. As the image is being split into quadrants, the program computes the standard deviation and mean of the pixel values in each quadrant.

If the standard deviation is below the user-specified loss level, the entire quadrant is treated as a single pixel whose colour value is the mean. This prunes the recursion early and collapses visually uniform regions into a single leaf, dramatically reducing the size of the quadtree without noticeably changing the image.

The loss level gives the user direct control over the trade-off between file size and image fidelity — a low loss level preserves more detail, while a high loss level compresses more aggressively.

Reflections

What I like about this project is that it takes two ideas I'd learned in class — recursion and trees — and uses them to solve a problem that feels genuinely useful.

It also taught me something about lossy compression that I hadn't appreciated before: the interesting part isn't throwing data away, it's knowing which data can be thrown away without changing what the viewer perceives. That's what the loss level controls, and getting it right is what makes the difference between a compressed image and a ruined one.
